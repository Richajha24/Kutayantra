01

Security as Statecraft

The Arthashastra, authored by Kautilya (Chanakya), details the mandala theory of foreign policy, secret intelligence, and secure court-to-court communication.

In ancient Indian diplomacy, envoys and messengers travelled across open roads between kingdoms. Because roads were routinely monitored by rival spies (gūḍhapuruṣa), sensitive military counsel could not simply be sent in plain writing across the kingdom borders.

👁
The Core Principle:

“The road itself is not trusted.”

Every message passing along the highway must be assumed to be intercepted by observers.

02

The Same Problem, Formalized

In 1976, Whitfield Diffie and Martin Hellman published a landmark mathematical solution to this exact predicament: How can two parties establish a shared secret key over an insecure public channel?

Instead of relying on secret physical couriers, the algorithm relies on the mathematical asymmetry of one-way modular arithmetic.

  • Both parties agree on public parameters: a prime number p and a base generator g.
  • Each party selects a private secret exponent (a for Magadha, b for Avanti).
  • Each party computes a public value and transmits it over the insecure road.
  • Using the received public value and their own private secret, both courts calculate the exact same final key.
MAGADHA PUBLIC VALUE
A = ga mod p

Sent across the road from Magadha to Avanti

AVANTI PUBLIC VALUE
B = gb mod p

Sent across the road from Avanti to Magadha

SHARED SECRET DERIVATION
K = Ba mod p = Ab mod p = gab mod p

Identical key computed independently by both courts

05

Why Do Both Courts Get the Same Key?

Interactive proof demonstrating why the two independent calculations yield identical results

Magadha's Calculation

Magadha receives Avanti's public value B = gb mod p and raises it to Magadha's secret a:

1. KMagadha = Ba mod p
2. KMagadha = (gb mod p)a mod p
3. KMagadha = (515)6 mod 23 = 590 mod 23 = 2
= ALGEBRAIC EQUIVALENCE gab mod p

Avanti's Calculation

Avanti receives Magadha's public value A = ga mod p and raises it to Avanti's secret b:

1. KAvanti = Ab mod p
2. KAvanti = (ga mod p)b mod p
3. KAvanti = (56)15 mod 23 = 590 mod 23 = 2

The Mathematical Magic: Exponent Multiplication Property

Because modular arithmetic respects exponent multiplication, (gb)a ≡ (ga)b ≡ ga × b (mod p). Neither party needed to know the other's private secret; they simply combined their secret with the received public message.

06

Limitations & Security Notes

Educational context, real-world cryptography, and historical distinction

🔢

Small Primes vs. Real Cryptography

This simulator uses small numbers (like p = 23) so human users can easily trace the steps. Small primes can be broken by trial exponentiation in microseconds.

Production Diffie–Hellman (or Elliptic Curve Diffie–Hellman) uses prime numbers that are 2048 to 4096 bits long (hundreds of digits).

🛡️

Lack of Authentication (MITM Risk)

Basic Diffie–Hellman does not authenticate the identity of the senders.

An active spy on the road could intercept Magadha's messenger, impersonate Avanti, and establish separate keys with both courts (a Man-in-the-Middle Attack). Modern TLS uses digital signatures / certificates to prevent this.

📜

Conceptual Mapping Disclaimer

The relationship between the Arthashastra and Diffie–Hellman is an educational conceptual metaphor.

Kautilya expertly analyzed spy networks, secret codes, and statecraft in 300 BCE, but did not describe modular exponentiation arithmetic.
